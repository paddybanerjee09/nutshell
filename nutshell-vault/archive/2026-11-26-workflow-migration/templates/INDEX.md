# Note templates

Use only the template needed for the current change. Replace placeholders with observed facts and actual source links; do not treat a template as evidence.

- [Feature context](FEATURE_CONTEXT.md): concise current state.
- [History entry](HISTORY_ENTRY.md): a meaningful change, rationale, and verification.
- [Decision](DECISION.md): a choice affecting future work.
- [Run handoff](RUN_HANDOFF.md): actual progress and the next executable step.

Follow [the memory protocol](../workflows/MEMORY_PROTOCOL.md). Do not create empty notes merely to fill the folder structure.
